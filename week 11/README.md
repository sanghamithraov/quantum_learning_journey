Week 11: Quantum Error Correction & Noise Models

Objective

Study the effects of environmental noise on quantum systems and explore foundational quantum error correction techniques using Python and Qiskit.

Topics Covered

1. Quantum Noise and Decoherence

- Understanding environmental noise in quantum systems.
- Exploring how noise affects quantum states and measurement outcomes.
- Simulating the effects of environmental noise.

2. Three-Bit Bit-Flip Code

- Studied the three-bit repetition code.
- Explored how bit-flip errors affect encoded quantum information.
- Simulated the circuit and observed measurement results.

3. Three-Bit Phase-Flip Code

- Studied the three-bit phase-flip error correction approach.
- Explored phase errors and their effects on quantum states.
- Implemented and executed the simulation.

4. Environmental Noise Simulation

- Simulated noisy quantum operations.
- Observed measurement outcomes under environmental noise.
- Compared the behaviour of quantum circuits under different conditions.

Technologies Used

- Python
- Qiskit
- Qiskit Aer (where used)
- NumPy

Project Files

- "error_correction_noise.py" — Python implementation of bit-flip, phase-flip and environmental noise simulations.

How to Run

Install the required libraries:

pip install qiskit qiskit-aer numpy

Run the program:

python error_correction_noise.py

Execution

The program was executed successfully and produced measurement results for:

1. Three-bit bit-flip code
2. Three-bit phase-flip code
3. Environmental noise simulation

Learning Outcome

Gained practical exposure to quantum error correction, quantum noise, decoherence and the simulation of noisy quantum circuits using Python and Qiskit.
